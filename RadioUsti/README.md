# RadioÚstí — Starter Project

This ZIP is a **project skeleton for Claude to edit**, not a finished add-on. It contains linked Behavior Pack and Resource Pack manifests, a minimal script entry point, and the intended folder structure. Most gameplay features, textures and models have deliberately not been implemented yet.

## Use
1. Extract this ZIP.
2. Open the project folder in the coding environment Claude will use.
3. Provide Claude with your full RadioÚstí specification and ask it to follow `docs/CLAUDE_TASK.md`.
4. Ask Claude to edit this project directly and deliver one complete `.mcaddon`, plus a validation report.

Target: Minecraft Bedrock Edition 1.26.50. Runtime compatibility must still be tested in Minecraft.

# Výtah Transporta TO 250 (Godot 4)

Otevři složku v Godotu 4.3+ a spusť (F5).

Ovládání: WASD chůze, myš rozhled, LMB / E použít, Esc uvolní myš.

Postup: VOLAT → otevři šachetní dveře → shrň mříž → nastup → zavři mříž i dveře → zmáčkni patro (0–3) na panelu vpravo v kabině. STOP zastaví mezi patry.

Zvuky se generují v kódu. Vlastní nahrávky (např. z videa) ulož do `sounds/` jako `motor.ogg`, `relay.ogg`, `door.ogg`, `gate.ogg`, `brake.ogg`, `buzz.ogg` – mají přednost.

# Výtah Transporta TOV 250 (Godot 4)

Panelák: 2 podzemní podlaží (-2 sklep s krabicemi dílů, -1 sklad), přízemí a 11 pater s byty, nahoře strojovna.
Otevři složku v Godotu 4.3+ a spusť (F5).

**PC:** WASD chůze, myš rozhled, LMB / E použít (do prázdna = odložit díl), R reset mapy, Esc myš.
**Mobil:** joystick vlevo, rozhled tažením vpravo, tlačítko POUŽÍT, tlačítko RESET.

- Jízda: VOLAT → dveře → mříž → nástup → zavřít → patro -2…11 na panelu.
- Byty: 3 v každém patře, dveře se jmenovkami, nábytek, okna.
- Poruchy: kabina občas uvízne mezi patry.
- Požár: šíří se po patře i nahoru, stěny a nábytek černají, nábytek se rozpadá. Hasicí přístroj (3 použití) u každých dveří výtahu.
- Sekera (přízemí): rozbité díly odpadávají jako fyzikální úlomky.
- Montážní klíč (přízemí): odmontovaný díl neseš v rukou; náhrady jsou v krabicích ve sklepě (-2).
  Tři modely: **Transporta TOV 250**, **Helgos** (modernizovaná Transporta), **KONE** (automatické posuvné dveře).
  Díly: šachetní dveře a přivolávač v každém patře zvlášť, dveře kabiny, panel, osvětlení, motor, řízení.
  Modely jdou míchat; dokud nějaký díl chybí, výtah nepojede.
- Rozvaděč ve strojovně opraví výtah, pult REKONSTRUKCE mění barvu.
- Evakuační plán a zelené EXIT nad schodištěm v každém patře.
- Nouzové okno v kabině: urvi drátěné sklo a prolez ven do nejbližšího patra (při uvíznutí nebo požáru).
- Transporta (původní motor + řízení) jede i při požáru a po poškození; Helgos/KONE se zablokují.
- 4× STOP během 3 s: brzda povolí, kabina spadne volným pádem na dno a rozbije se (hráč přežije).
